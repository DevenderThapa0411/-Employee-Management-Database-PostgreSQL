# -Employee-Management-Database-PostgreSQL
 # 👨‍💼 Employee Management Database | PostgreSQL

## 📌 Project Overview

This project demonstrates the design and management of an Employee Management Database using **PostgreSQL**. It showcases SQL fundamentals, including database creation, CRUD operations, schema modifications, constraints, and data retrieval through real-world business scenarios.

The project is designed to strengthen SQL skills required for Data Analyst and Database Management roles.

---

## 🎯 Objectives

- Create and manage an employee database.
- Perform CRUD (Create, Read, Update, Delete) operations.
- Maintain data integrity using SQL constraints.
- Modify database schema using DDL commands.
- Practice SQL queries for real-world business operations.

---

- SQL

## 📂 Database Features

### Table Creation
- Created an Employee table with:
  - Primary Key (SERIAL)
  - NOT NULL Constraints
  - CHECK Constraints
  - Appropriate Data Types

### CRUD Operations
- Insert employee records.
- Retrieve employee information.
- Update employee salary and age.
- Delete employee records based on conditions.

### Schema Modifications
- Added new columns using `ALTER TABLE`.
- Renamed existing columns.
- Changed column data types.
- Maintained database structure according to business requirements.
